작가작업실 JEJU 최종 One-Page · 2026-10-21

최종 승인 시안 01 KEY VISUAL, 브랜드 소개, 02 SPACE, 03 PROGRAM,
04 OPEN HOURS, 05 LOCATION, Footer까지 하나의 HTML에 구현했습니다.

사용 방법:
1) index.html + assets 폴더를 함께 서버(Vercel 등)에 업로드합니다.
2) 사용자의 KakaoLight(2).ttf, KakaoRegular(2).ttf, KakaoBold(2).ttf 원본을
   각각 KakaoLight.ttf / KakaoRegular.ttf / KakaoBold.ttf 이름으로 바꿔
   assets/fonts 폴더에 직접 복사합니다. 폰트는 제공 패키지에 포함되지 않습니다.
3) 브라우저 탭 아이콘은 assets/favicon.ico, favicon-32.png로 설정했습니다.
4) 네이버 지도 API는 사용하지 않습니다. 지도 이미지 확대·축소·드래그는
   사진 범위 내에서만 가능합니다. 지도 바깥 영역을 탐색하려면 네이버 지도 열기를 사용하세요.
5) 독서모임/글쓰기 클래스 공지 및 운영시간 안내 링크는 전달받은 네이버 플레이스 URL을 적용했습니다.
6) 모든 본문 문장은 이미지가 아니라 HTML 텍스트로 포함했습니다.

설명: 확정된 이미지 시안은 디자인 가이드입니다. 웹에서는 글자 확대 및 모바일 반응형을 위해
텍스트와 사진을 분리하여 구현하므로 정지 이미지와 서체 줄바꿈/사진 크롭은 미세하게 달라질 수 있습니다.
